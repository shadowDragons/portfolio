# 什么是二进制

二进制是只用 0 和 1 两个符号来表示和计算所有数字的一套方法。你现在看的视频、听的声音、手机里存下的照片，底层全是一长串 0 和 1。

![两个手绘数字方块 0 和 1，辐射连接视频、声音、照片三个小图标](/blog/什么是二进制-只用-0-和-1-如何数数-换算并表达一切内容/scene-1-1.png)

## 三个要回答的问题

要真正理解二进制，需要依次回答三件事：

- 为什么计算机偏偏选了 0 和 1 这两个符号；
- 二进制怎么数数、怎么换算成我们熟悉的十进制；
- 它为什么能表达文字、图像和指令。

![三张卡片并排：选择 0 和 1 的原因、数数与换算十进制、表达文字图像指令](/blog/什么是二进制-只用-0-和-1-如何数数-换算并表达一切内容/scene-2-2.png)

## 计数规则：满 2 进 1

十进制有十个符号，从 0 数到 9，再往上就进一位。二进制的规则完全一样，只是符号只有两个，所以满了 2 就进位。

![左侧十进制 0 到 9 与满 10 进 1，右侧二进制只有 0 和 1 与满 2 进 1](/blog/什么是二进制-只用-0-和-1-如何数数-换算并表达一切内容/scene-3-3.png)

这一点很关键：二进制不是某种神秘编码，它就是一套换了符号数量的计数规则。

![横向流程节点 0、1、10、11、100，下方标注对应十进制 0、1、2、3、4](/blog/什么是二进制-只用-0-和-1-如何数数-换算并表达一切内容/scene-4-4.png)

具体数一遍就清楚了。从 0 开始，写下 1，再往下就没有第二个符号可用了，只能进位，得到 10，读作“一零”，它代表十进制的 2。接着是 11，代表 3。再进一步就变成 100，也就是十进制的 4。你会发现，位数增加得很快，但每一位的规律和十进制是同一套。

## 换算：每位权重按 2 的幂递增

![数字 1011 四位引线标注权重 8、4、2、1，下方算式 8+0+2+1=11](/blog/什么是二进制-只用-0-和-1-如何数数-换算并表达一切内容/scene-5-5.png)

每一位的权重规律值得单独看一眼。十进制里，一个数从右往左，每一位分别是 1、10、100、1000，每往左一位乘 10。二进制里，这个倍数换成 2，从右往左依次是 1、2、4、8、16。

所以看到 1011，就从左往右读成 8 加 0 加 2 加 1，结果是 11。这就是二进制转十进制的全部操作：把每一位上为 1 的权重加起来。

![两列对比两种状态与十种电压等级，按状态示意、能否分辨、容错、电路复杂度逐行比较](/blog/什么是二进制-只用-0-和-1-如何数数-换算并表达一切内容/scene-6-6.png)

## 硬件为什么选择二进制

![左侧写价值不在好读，右侧写价值在好造并交给极简单电路执行，中间用手绘小桥连接](/blog/什么是二进制-只用-0-和-1-如何数数-换算并表达一切内容/scene-7-7.png)

答案在硬件里。计算机的最小计算单元靠电路状态工作，最稳定、最容易区分的状态只有两种，比如有电压和没电压、开关通和断。

如果硬要电路在一根线上区分十种电压等级，干扰一点、温度变一点，就分不清了，出错率高得多。只判断“有”和“没有”，容错空间大，电路也能做得更简单、更省电。

![三格模块分别为文字 A=65=1000001、图像小方格与数值、声音波形采样点](/blog/什么是二进制-只用-0-和-1-如何数数-换算并表达一切内容/scene-8-8.png)

理解这一点，就能明白二进制的价值不在于好读，而在于好造。同样的逻辑，用两个状态表达的规则可以交给极简单的电路去执行。所以不是计算机先喜欢上了二进制，而是工程上只能这样选择，二进制是最稳稳落在电路特性上的答案。

## 数字之外：文字、图像与声音

![仪表盘式卡片列出 bit 最小单位、8 bit = 1 byte、256 种状态、0 到 255 整数与更大容量单位](/blog/什么是二进制-只用-0-和-1-如何数数-换算并表达一切内容/scene-9-9.png)

再看二进制怎么表达数字以外的东西。所有内容都要先被换成数字，再被换成 0 和 1。

文字靠编码表，比如英文字母 A 会存成数字 65，写成二进制是 1000001；汉字在统一码里也有各自的编号，同样落到 0 和 1 上。图像是把画面切成很多小方格，每个方格的亮度或颜色用数字表示。声音则是按时间采样，把每个采样点的音量记成数字。

![中心手绘开关符号向外辐射与、或、非三个逻辑节点，标注加减乘除被拆成开关动作](/blog/什么是二进制-只用-0-和-1-如何数数-换算并表达一切内容/scene-10-10.png)

### 存储单位：bit 与 byte

一个二进制位叫 bit，也就是一位 0 或 1，是信息的最小单位。把 8 个 bit 打包起来，就是 1 个字节，byte。

![两行分镜：敲键到编码到存成字节到二进制，数字文件到采样值到模拟电压到喇叭震动](/blog/什么是二进制-只用-0-和-1-如何数数-换算并表达一切内容/scene-11-11.png)

8 位能组合出 256 种状态，所以一个字节可以表示 0 到 255 的整数，也刚好够装下英文字母和常见符号。更大的容量单位，比如千字节、兆字节、吉字节，都是在这个字节的基础上翻倍累加出来的。

## 逻辑运算：加减乘除都是开关动作

还有一个容易被忽略的细节：计算机里所有运算，最终都靠最基础的几个逻辑操作组合出来，比如“与”“或”“非”。

这些操作直接对应电路里的开关组合，所以加减乘除并不是电路里真的有一台小算盘，而是被拆成大量开关动作。二进制之所以重要，是因为它和这套逻辑天然对齐。

## 实践场景：键盘与音乐

回到现实场景看一遍会更直观。你在键盘上敲下一个字母，键盘把按键位置转成一段编码，计算机把它存成字节，再用二进制表示。

播放一首歌时，数字文件里的采样值被一路还原成模拟电压，推动喇叭震动。这些环节里，0 和 1 一直存在，只是被包装成了你能看见和听见的东西。

## 限制与常见误区

理解二进制时，有几点容易被误解：

- 二进制不是神秘编码，只是符号数量更少的计数规则，进位逻辑与十进制完全同构。
- 计算机选择二进制不是因为好读，而是因为好造：只判断通和断，容错高、电路简单。
- 一位不等于一个字节：一位 0 或 1 叫 bit，8 个 bit 才是 1 个字节。
- 加减乘除不是电路里真的有一台小算盘，而是被拆成大量开关动作。
- 二进制位数增长得很快，但每一位的规律与十进制是同一套。

## 常见问题

![三层叠放结构：顶层计数规则、中层硬件最可靠、底层内容统一底座](/blog/什么是二进制-只用-0-和-1-如何数数-换算并表达一切内容/scene-12-12.png)

### 二进制怎么换算成十进制？

把每一位上为 1 的权重加起来。权重从右往左依次是 1、2、4、8、16，每往左一位乘 2。例如 1011 就是 8 加 0 加 2 加 1，等于 11。

### 为什么电路不直接区分十种电压等级？

因为一根线上要区分十种电压等级时，干扰一点、温度变一点就分不清了，出错率高得多。只判断“有”和“没有”，容错空间更大，电路也更简单、更省电。

### 8 个 bit 能表示多少种状态？

8 位能组合出 256 种状态，因此一个字节可以表示 0 到 255 的整数。

## 总结：记住三个层次

二进制真正值得记住的，是三个层次。它是一套只有两个符号的计数规则，满 2 进 1，每位权重按 2 的幂递增。它是硬件层面最可靠的选择，只判断通和断，容错高、电路简单。它还是一切内容的统一底座，文字、图像、声音、程序指令，都要先落成数字，再落成 0 和 1。

理解了这三个层次，再看计算机里的任何数据，你都能想到那串开关状态的影子。
